Praat Scripts (Japanese Edition)

Release v1.0.1 GitHub Repository
言語学・音声学における音響分析処理を自動化するための Praat スクリプト集および拡張機能。

Mietta Lennes 氏の SpeCT (Speech Corpus Toolkit for Praat) および FieldDB/Praat-Scripts を基に、ダイアログの日本語化、Praat 6.x 系関数構文への最適化、および TSV 形式でのデータ出力に対応しています。

Windows 版をダウンロード Praat-JapaneseTools-Setup.exe macOS 版をダウンロード Praat-JapaneseTools-Setup.pkg
Version 1.0.1 | Windows 64-bit / macOS (Intel & Apple Silicon) | 管理者権限不要

プラグイン導入

Praat のプラグイン機能として導入することで、スクリプトファイルを個別に読み込むことなく、メニューバーおよびアクションパネルから直接機能を実行できます。

1. Windows用インストーラー（.exe）

  1. 上部のダウンロードボタンから Windows 版（Praat-JapaneseTools-Setup.exe） を取得します。
  2. ダウンロードしたファイルを実行します（管理者権限は不要です）。
  3. 「インストール先フォルダーの指定」画面が表示されたら、保存場所を変更せずデフォルトのまま「次へ」をクリックします（※Praat がプラグインを自動認識するために既定のパスが必要です）。
  4. 画面の指示に従ってインストールを完了します。
  5. Praat を起動（または再起動）します。
【注意】Windows による保護の警告が表示された場合

インストーラー実行時、Microsoft Defender SmartScreen により「Windows によって PC が保護されました」（発行元: 不明な発行元）という青い画面が表示される場合があります。

※これは個人・研究用途のオープンソースソフトウェアであるため、有償の組織用コード署名を行っていないことによる仕様です。危険なファイルではありませんので、以下の手順で実行してください。

  1. 画面内の説明文にある「詳細情報」（下線付きリンク）をクリックします。
  2. 右下に表示される「実行」ボタンをクリックします。
▲ 「詳細情報」をクリックすると右下に「実行」ボタンが現れます
反映されるメニュー位置:
・メニューバー: Praat → 日本語音声ツール (JA)
・アクションボタン: Sound または TextGrid オブジェクト選択時に右側パネルに 日本語ツール (JA) ボタンが表示されます。

アンインストール: Windows の「設定」 → 「アプリ」 → 「インストールされているアプリ」から削除できます。

2. macOS用インストーラー（.pkg）

  1. 上部のダウンロードボタンから macOS 版（Praat-JapaneseTools-Setup.pkg） を取得します。
  2. ダウンロードしたファイルをダブルクリックして実行し、画面の指示に従ってインストールを完了します（Intel / Apple Silicon 共通対応）。
  3. Praat を起動（または再起動）します。
【注意】macOS のセキュリティ警告（Gatekeeper）が表示された場合

macOS では、インターネットからダウンロードした未署名のインストーラーを開く際に「開発元を検証できないため開けません」または「悪質なソフトウェアかどうかを Apple では確認できないため開けません」と表示され、通常のダブルクリックでは起動がブロックされる場合があります。

※Apple Developer の有償公証を受けていないことによる macOS の標準セキュリティ動作です。以下のいずれかの手順で一度許可することで正常にインストールできます。

方法 A: 右クリックから開く（最も簡単・推奨）
  1. ダウンロードした Praat-JapaneseTools-Setup.pkg を Control キーを押しながらクリック（または右クリック／トラックパッドの二本指タップ）します。
  2. 表示されたメニューから 「開く」 を選択します。
  3. 警告ダイアログが表示されたら、ダイアログ内の 「開く」 ボタンをクリックするとインストーラーが起動します。
方法 B: 「システム設定」から許可する
  1. 画面左上のアップルメニュー（） → 「システム設定」（macOS 12以前は「システム環境設定」）を開きます。
  2. 左メニューの 「プライバシーとセキュリティ」 を選択し、画面を下方へスクロールします。
  3. 「セキュリティ」欄にある「"Praat-JapaneseTools-Setup.pkg" は開発元を確認できないため〜」の横にある 「このまま開く」 をクリックします。
反映されるメニュー位置:
・メニューバー: Praat → 日本語音声ツール (JA)
・アクションボタン: Sound または TextGrid オブジェクト選択時に右側パネルに 日本語ツール (JA) ボタンが表示されます。

アンインストール: プラグインフォルダ（~/Library/Preferences/Praat Prefs/plugin_JapaneseTools/）内の uninstall.command をダブルクリックすることで、いつでも安全に登録解除・削除できます。

3. Praat スクリプト（install.praat）

OS（Windows / macOS / Linux）に関わらず、Praat アプリケーション上から直接登録を行う手順です。

  1. 本リポジトリの installer/install.praat を Praat で開きます（メニューの Praat → Open Praat script... またはドラッグ＆ドロップ）。
  2. スクリプトウィンドウの Run → Run を実行します。
  3. 確認ダイアログの「インストール実行」をクリックします。
  4. Praat を再起動します。

4. シェルスクリプト / バッチファイル

リポジトリを作業ディレクトリにクローンまたは展開してシンボリックリンク／ジャンクションを作成する手順です。

Windows の場合:

installer\install.bat

macOS / Linux の場合:

bash installer/install.sh

単体実行

プラグインとしてインストールを行わず、必要なスクリプトファイルのみを個別に実行する手順です。

  1. Praat を起動し、メニューバーの Praat → Open Praat script... を選択します。
  2. 実行対象のスクリプト（例: scripts/segmentation/extract_intervals_to_wav.praat）を選択して開きます。
  3. スクリプトエディタのメニュー Run → Run（ショートカット: Ctrl + R / Cmd + R）を実行します。
  4. パラメータ設定ダイアログが表示されるため、対象音声や TextGrid が配置されたディレクトリパス、Tier 番号等を指定して OK を押下します。
  5. 処理結果は指定した出力ディレクトリに TSV ファイルまたは WAV ファイル等として保存されます。

収録スクリプト

各スクリプトは scripts/ 配下の機能別ディレクトリに格納されています。出力ファイル形式は集計・後続処理に適したタブ区切りテキスト（TSV）に統一されています。

分野 スクリプト名 機能概要 対象オブジェクト
切り出し extract_intervals_to_wav.praat TextGrid のラベル区間ごとに音声を分割し、個別 WAV として保存 Sound + TextGrid
検出 mark_pauses.praat 無音・ポーズ区間を音量基準で自動検出し、TextGrid に境界を挿入 Sound
フォルマント collect_formant_data.praat 各母音区間の中央点におけるフォルマント（F1〜F5）および帯域幅を測定 Sound + TextGrid
ピッチ collect_pitch_data.praat 各区間の基本周波数（F0）の平均値・中央値・最大/最小値・標準偏差を集計 Sound + TextGrid
時間測定 calculate_segment_durations.praat 各区間の開始・終了時刻および継続時間（秒／ミリ秒）を集計 TextGrid
周波数変換 change_sample_rate.praat フォルダ内の音声ファイルを指定サンプリングレートへ一括変換 Sound（ファイル一括）
チャンネル convert_stereo_to_mono.praat ステレオ音声（2ch）からモノラル音声（1ch）へ一括変換 Sound（ファイル一括）
可視化 draw_formant_chart.praat 測定されたフォルマントデータから F1-F2 母音散布図を描画 Table
